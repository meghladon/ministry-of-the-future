# The Ministry of the Future

A small project testing whether **vAustralia** — an adaptation of [Polis](https://compdemocracy.org/), the deliberation tool used by [vTaiwan](https://compdemocracy.org/case-studies/2014-vtaiwan/) to resolve real political deadlocks in Taipei — could help Australians think together about what this country should become.

## What's in this repo

- **`index.html`** — The Ministry of the Future website. The project's public face: the case for why this work matters, the Taiwan story, the roadmap, and the entry point into vAustralia.
- **`vaustralia.html`** — vAustralia v1.1, the deliberation tool itself. A single Polis-faithful round wired to Supabase.

## Running it

This is a static site. There's no build step. Open `index.html` in a browser and it works.

For the live deployment, both pages are served from GitHub Pages.

## The dry run

vAustralia v1.1 is currently running its first round, with the question:

> *Finish the sentence: in an ideal world…*

It's an experiment. We're testing whether the tool resonates here, whether the bridging algorithm finds anything interesting at small scale, and whether real Australians want to think about questions like this. The answers will shape what we do next.

## Built on

- [Polis](https://compdemocracy.org/) — open-source deliberation tooling from the Computational Democracy Project
- [Supabase](https://supabase.com/) — for the multi-user voting backend
- [vTaiwan](https://compdemocracy.org/case-studies/2014-vtaiwan/) — the precedent that proved this method could shape real legislation

## Built in public

This is a small, evolving project. The roadmap on the website itself is the source of truth for what's been done and what's coming next. Suggestions welcome — there's a form at the bottom of the roadmap section, or you can open an issue here.
